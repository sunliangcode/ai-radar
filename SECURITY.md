# Security Policy

## Supported Versions

| Version | Supported |
|---------|-----------|
| 0.1.x   | Yes |
| < 0.1   | No |

## Reporting a Vulnerability

Please report security vulnerabilities via [GitHub Security Advisories](https://github.com/sunliangcode/ai-radar/security/advisories/new) (private disclosure).

Do not open public issues for security reports.

We will acknowledge receipt and work on a fix, but no specific response timeline is guaranteed.
